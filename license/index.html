Template license

Last updated: October 30, 2026

When you buy a template, you get a license to use it. You can change it as much as you like and use it for real projects. You can’t resell the template itself.

License types

HTML VERSION

One website

Use the template for one website, for yourself or for one client. Making another site? Buy it again for that site.

WORDPRESS VERSION

GPL licensed

WordPress themes are released under the GNU General Public License v2 or later, so you can use them on as many websites as you like. Each purchase includes 12 months of updates and support.

Buying both versions together covers one website. The rest of this page applies to the HTML versions; the WordPress themes follow the GPL, which is included in each theme.

You can

  • Edit, restyle and rebuild any part of the template
  • Use it for commercial websites, including client work you charge for
  • Hand the finished website to your client

You can’t

  • Resell, share or give away the template files, changed or unchanged
  • Include the template in another template, theme or product for sale
  • Claim the template’s design or code as your own original work for resale

Fonts, icons and other parts

Templates use only openly licensed fonts and icons. Each one keeps its own license, listed with links in the template’s documentation. Photos in our demos are for preview only and aren’t included in the download.

Ownership

K&A Digital Studio keeps the copyright in the template. The license lasts forever, as long as you follow these terms.

Questions about what’s allowed? Ask us before you buy.
