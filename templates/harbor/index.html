A closer look

Questions

Do I need to know how to code?
No. The HTML guide walks you through changing text, photos and colors with a free text editor, and putting the site online. Prefer pointing and clicking? Choose the WordPress version.
HTML or WordPress: which should I choose?
If you already have WordPress hosting, or want to edit everything visually, choose WordPress. If you want the fastest, simplest site with free hosting, choose HTML. Not sure? The live demos show both.
Where can I host it?
The HTML version runs anywhere that serves plain files: Netlify, Cloudflare Pages, GitHub Pages or your current web host. The WordPress version runs on any WordPress hosting.
Does it work with my booking tool?
The contact page has a spot for an embed from booking tools such as Calendly, Square, Jobber or Housecall Pro. The guide shows where to paste yours.
Are the demo photos included?
No. The demo uses free stock photos for preview only. The download has placeholders, so your site shows your own work.
What if something doesn’t work?
Email us. Support covers setup questions and bugs for 12 months. See the refund policy.
