Questions

Do I need to know how to code?
No. The docs walk you through changing text, images and colors with any text editor, and putting the site online for free.
Where can I host it?
Anywhere that serves plain files: Netlify, Cloudflare Pages, GitHub Pages, or your current web host.
Does it work with my booking tool?
The booking section is ready for embed codes from common booking and scheduling tools. The docs show where to paste yours.
What if something doesn’t work?
Email us. If we can’t fix it, you get a refund.
